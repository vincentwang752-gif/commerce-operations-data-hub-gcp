# 广告与红人归因规则

## 证据优先级

1. 订单使用的专属 Coupon，且 Coupon 唯一归属某个红人或 Campaign。
2. Shopify 落地页或订单属性中的 Click ID / UTM，可与广告或红人链接精确匹配。
3. GA4 会话来源、Campaign 和购买路径，可作为行为证据。
4. 广告平台自报转化，只作为平台口径，不直接等同 Shopify 订单。
5. 客户问卷或人工确认，用于补充“首次知道”和“最终说服”触点。

## 合创广告

- 广告表同时关联平台广告对象和红人。
- 红人来源可以是自有表格、Shopify Collabs、平台代理商或其他供应商。
- 新红人先进入红人主表，`来源` 标记为平台代理/供应商，避免只存在广告备注里。
- 费用拆分为媒体费、红人合作费、服务商费，不能全部塞进广告花费。

## 多触点

- 首次发现、内容助攻、最后点击、Coupon 和购买后问卷分别保存。
- 订单可以有多个触点，但只能有一个最终财务订单记录。
- 不确定归因保留为“不确定”，不要为了报表完整而强行归因。

## UTM 规范

- 全部小写，单词使用下划线。
- `utm_source` 表示平台或合作方；`utm_medium` 表示 cpc、paid_social、creator、email 等媒介。
- `utm_campaign` 使用稳定 Campaign Key；`utm_content` 使用 Ad/Creative/Creator 内容键。
- UTM 中禁止邮箱、手机号、订单号等个人信息。
