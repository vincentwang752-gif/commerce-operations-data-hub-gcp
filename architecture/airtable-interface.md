# Airtable Interface 设计

底层保持规范化的 11 张表，管理层通过一个 Interface 查看业务，不需要逐张翻表。

## 广告投放

- 广告系列数量和平台分布
- 广告数量与明细
- 日级花费、曝光、点击、平台收入和趋势
- Google/Meta 不同账户和平台代理来源

## GA4运营与用户触点

- 活跃用户、会话、高意向未购、购买用户
- GA4 与 Shopify 订单/收入差值趋势
- 渠道会话、购买者和落地页表现
- 只看产品、加购未结账、结账放弃、高意向未购、已购等人群
- 平台归因与 Shopify 财务口径并列展示

## 客户与订单

- 客户数量、客户明细
- 订单数、净收入、退款和时间趋势
- 订单明细和同步状态

## 归因与生命周期

- 触点数量、来源分布、归因收入和证据等级
- VOC 阶段、奖励/延保审核和客户生命周期状态

## 红人与内容

- 红人、合作、内容资产数量与状态
- 内容关联收入、Coupon、UTM 和合创广告
- 自有合作、Collabs、平台代理和供应商合作的统一视图
